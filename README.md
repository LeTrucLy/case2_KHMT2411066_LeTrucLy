# TASK MANAGER

Ứng dụng quản lý và giao công việc nhóm.

## Thông tin sinh viên

- **Họ và tên:** Lê Trúc Ly
- **Mã số sinh viên:** KHMT2411066
- **Tên bài thực hành:** Case 2 – Task Manager

## Công nghệ sử dụng

- **Frontend:** Flutter (Dart)
- **Backend:** Node.js, Express.js
- **Cơ sở dữ liệu:** MongoDB
- **API:** REST API
- **Quản lý mã nguồn:** Git và GitHub

## Chức năng Buổi 1

1. Đăng ký tài khoản người dùng.
2. Đăng nhập và xác thực bằng API.
3. Mã hóa mật khẩu trước khi lưu vào cơ sở dữ liệu.
4. Hiển thị danh sách công việc từ MongoDB.
5. Xem thông tin chi tiết công việc.
6. Kết nối Flutter với Backend Node.js.

## Cấu trúc dự án

- `api/`: Backend Node.js và REST API.
- `lib/`: Mã nguồn ứng dụng Flutter.
- `lib/services/`: Xử lý kết nối API.
- `lib/database/`: Các tệp hỗ trợ cơ sở dữ liệu.
- `test/`: Kiểm thử Flutter.

## Trạng thái thực hiện

**Buổi 1:** Đã triển khai các chức năng chính và chạy thử trên Android Emulator.

**Buổi 2 và Buổi 3:** Chưa triển khai.
